# Customer package upgrades — KP MASTER 1.2.11

Windows customers can upgrade an already registered Basic package without typing activation codes or reinstalling.

Owner:
1. Open the Owner Activation tool with your existing owner access.
2. In the customer's purchase history row, click **Upgrade package**. This fills the same customer name, System ID and activation period.
3. Choose Full Advanced or the additional purchased features. Keep all previously purchased features. Preserve the expiry date or extend it; preserve Permanent when the existing licence is permanent.
4. Click **Save package upgrade file** and send the `.kplicense` file to that customer.

Customer:
1. Open **My Package / Upgrade** at the bottom of the sidebar.
2. Click **Import upgrade file** and select the owner's file.
3. New features become available immediately. The open chart and saved charts remain intact; registration is reused.

A cancelled or invalid import keeps the installed licence unchanged. Upgrades must be signed by the same owner, target the same registered customer/device, retain existing features, and preserve or extend the activation period. A customer cannot unlock paid features just by changing a setting. This flow works offline; the owner sends a file after approving the purchase.

This new file-import shortcut is for the Windows Customer edition. Android's existing registration/purchase screen is unchanged.
