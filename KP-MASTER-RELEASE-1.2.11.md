# KP MASTER 1.2.11

Release date: 21 October 2026. Event significators mode now follows the Transit Reader rule only: selected moving planets are checked through event-significator star AND sub lords. DBA supplies dates only; Rashi, transit houses, RP and additional planet gates do not filter this mode. One scan produces daily ephemeris-style rows and exact simultaneous matching windows; the pictured rule-summary panel is removed. Rule-matching windows do not guarantee a real event date.

This refresh includes theme-aware Western aspect tables, merged Help & Shortcuts with English/Marathi tutorials, persistent event-significator chips in all four Transit modes, the Birth Date and Time label, removal of the numbered Kundali heading, single-language display choices and English button hover labels. The Customer demo script no longer shares an ID with its banner. Windows Customer adds My Package / Upgrade for signed-file upgrades without typing new codes; Owner Activation adds an upgrade-file action. Android includes mobile-friendly Astrologer Settings and Share on WhatsApp for PDF reports. The Activation tool defaults to the Full Advanced customer package; existing custom licence restrictions remain in force.

Windows: Windows 10/11 x64. Owner calculator, activated Customer calculator and the separate Owner Activation tool retain their existing identities. Installers are unsigned; native Windows installation has not been run here.

Activation: existing signing identities and customer keys are preserved. Dated keys expire at 23:59:59.999 UTC on the chosen date. Customer access is rechecked while open. On first launch of the 1.2.11 activation tool, the visible history is cleared once; its previous file is retained locally as a recovery copy. Newly issued records persist on later launches.

Android: Android 9+. Version 1.2.11, versionCode 10217. Uses the same certificate as the prior fresh-install 1.2.8 APKs, so those installations can update. For an app with the older original certificate, export your backup before uninstalling/reinstalling. Physical-phone installation has not been tested here.

iPhone: no native IPA is included. Native packaging requires macOS/Xcode and Apple signing/provisioning. APK files are Android-only. The web editions require HTTPS hosting for iPhone use and have not been tested on a physical iPhone. Keep the unlocked Owner edition private.

HTML backup: extract completely and open KP-MASTER/index.html. The ZIP includes all available reference/data sources and a per-file checksum manifest. The workspace Kundali Backup and Report Photos folders contain instructions only; browser/device-local files and private keys are unavailable and are not included.

Checks: 44 desktop unit-test files; Android licence/demo tests; APK signatures/alignment and byte-parity; mobile browser exports/backups/A4 PDF; all three Windows installer payloads and packaged source verified.
