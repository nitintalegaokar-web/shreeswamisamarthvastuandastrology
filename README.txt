KP MASTER activation 1.2.1 — Windows x64 Setup.exe

All three Windows installers use version 1.2.1:

- KP-Master-Owner-Setup-1.2.1-x64.exe: unlocked full calculator for the owner.
- KP-Master-Setup-1.2.1-x64.exe: System ID locked calculator for customers.
- KP-Master-Owner-Activation-Setup-1.2.1-x64.exe: owner licence tool.

For easy activation, the customer clicks Save System ID file and sends the
text file. In the Activation tool, enter your existing key password, select
Open owner key, and check the green key-match confirmation. Select Open
customer System ID file, enter the customer's name, and create the licence.
Send the resulting .kplicense to the customer. Activate / Open software
imports that licence and opens the customer calculator automatically.
Keep your existing owner key; a new key needs a matching approved customer build.
Creating a licence in the owner tool does not activate a remote offline PC.

Installer includes installation wizard, desktop/Start menu shortcuts and uninstaller.
Application and package checks are performed on Linux. Native Windows installation
and execution were not available in this build environment.

1.2.1 matches the calculator release; activation behaviour is unchanged.
