KP Master Windows Setup 1.0.0 (64-bit)

This installs the same offline calculator delivered in the original portable executable. It is the unlocked edition: it does not include System ID activation or additional data encryption. Do not distribute this edition as a licensed client build. The owner-bound 1.1.0 installer requires the owner-exported public key.

Run KP-Master-Setup-1.0.0-x64.exe on Windows 10/11 (64-bit), choose the installation folder and finish the wizard. Open KP Master using its desktop or Start menu shortcut. All calculation/runtime files are included; no Python, Node.js, browser install or internet connection is required. The wizard installs for the current user without administrator elevation. Remove it through Windows Installed Apps; saved chart files and application data are preserved.

Package checks cover archive CRCs, installer/uninstaller metadata and application parity with the previously verified portable package. Installation on a native Windows computer has not been tested. This executable is unsigned.
