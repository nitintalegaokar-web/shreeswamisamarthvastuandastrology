KP MASTER Owner Activation tool 1.2.1

Offline owner utility for issuing licenses to customer System IDs. No private
owner key is packaged in this installer. Keep the private key and its password
securely on the owner's computer.

Run the Setup.exe on 64-bit Windows. Windows may show an unsigned publisher
warning because this installer is not code-signed.
