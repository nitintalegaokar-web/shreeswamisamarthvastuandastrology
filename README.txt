KP Master Owner Activation Windows Setup 1.0.0 (64-bit)

Run KP-Master-Owner-Activation-Setup-1.0.0-x64.exe to install the owner tool. Open KP Master Activation using its desktop or Start menu shortcut. This is the license issuing tool, not the calculator.

Set and confirm a password of at least 12 characters. Create owner key, save and securely back up the encrypted private key on your PC, then Export public key. Send only KP-Owner-Public-Key.pem to the developer so your locked calculator installer can be bound to your key. Never send the private key or password. Existing keys may be opened rather than recreated; keep the same key for the corresponding client build.

After clients provide their System IDs, open your key, enter the client name and ID, and create a permanent or dated .kplicense file. The client imports it to activate the correct locked build offline.

Uninstalling retains local license history. Keep separate private-key backups. This executable has no built-in owner key and is unsigned. Package inspection and Linux Electron owner workflow tests passed; native Windows installation remains untested.
