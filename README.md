# KP Panchang Studio 3.1 — supplied logo edition

Download KP_Panchang_Studio_v3_1_Setup.zip, extract it, then run
KP_Panchang_Studio_v3_1_Setup.exe. Close the previous app before updating.

The exact supplied KP Panchang Studio PNG is bundled as the default app, About,
report and South Indian chart logo. It is also the browser favicon and the
Windows launcher/installer icon, with seven native icon sizes (16–256 pixels).
The source PNG is preserved byte for byte; only icon-format conversion/resizing
was used for the Windows ICO. Prior custom logo preferences remain available.

Includes the version 3 chart fixes, menus, traditional monthly printing and MDB
place importer. The AllPlaces database is not preloaded; File > Import places
can read it locally. App menus and logo selection remain available offline.

Logo rendering, exact PNG identity, all launcher and installer icon resources,
615 packaged file hashes and ZIP integrity were checked. Modern/traditional
portrait/landscape yearbooks with the logo each retain 12 sheets. Windows native
execution remains untested in this Linux environment. The installer is unsigned.

The main repository branch is unchanged. Source and sample print files are
included alongside the installer download.
