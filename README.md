# KP Panchang Studio 2.0 — Windows download

Download `KP_Panchang_Studio_Setup.zip` using GitHub's Download raw file button.
Extract the ZIP, then run `KP_Panchang_Studio_Setup.exe`.

This branch contains the installer download only. The main application branch is unchanged.

The offline app supports calculated Pune / IST KP Panchang data for 1900–2500,
with twelve monthly print sheets per year in A4 landscape or portrait. It uses
Swiss Ephemeris / Moshier generated data and Krishnamurti ayanamsa. Future event
times depend on the Delta-T model; festivals and muhurta are not certified.
The installer is unsigned. Windows installation and file-URL startup still need
Windows verification; data, browser and PDF checks were completed on Linux.
