# KP Raphael astrology workspace

A browser-based Krishnamurti Paddhati calculator with Marathi worksheets, South and North Indian kundali layouts, and printable client reports. It runs locally without an application server, build step, or external assets.

The live windows follow the supplied reference layouts: cream forms, square controls, compact green calculation tables, pink position/aspect headers and a white Settings window. Birth and Horary entry keep personal details above two columns and comments below. Event Promise keeps its analysis and rules side by side; Nadi, Transit and matchmaking retain their reference arrangements. Open **Choose Indian city / village**, **Change place**, or **Open / Delete Saved Chart** to use the corresponding tools. Reports use dedicated A4 layouts, including a single-page Nadi kundali.

`index.html` is self-contained: its styling and JavaScript are embedded, so no companion files are needed. Open the HTML file in your browser, or start the development server from this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

The cloud environment already includes Python, Chromium, and Python Playwright. Each cloud task is isolated; use the existing checkout unless a separate worktree is explicitly requested.

## Using the calculator

- **Home** opens with the South Indian kundali, planet and house tables, birth and current ruling planets, a five-level Vimshottari window, and native details together. Switch the center tables between basic calculations, four-fold, six-fold and four-step views. **Expand workspace** gives the dashboard more room on desktop; compact screens stack the panels and allow table scrolling. The kundali scales to its panel without scrollbars, including on mobile. Home reflects the current worksheet data and saved chart. Select a dasha row to drill down through MD, AD, PD, SD and Prana; use the column headers to return. A reference date/time and Now button select the current path. The old Home MD/AD cards have been replaced; the calculation worksheets remain available. Rotate chart beside the kundali selects any natal house as the display reference without changing calculated cusps or significators.
- The ruling-planet tables show Ascendant, Moon, Rahu and Ketu with sign, star, sub and sub-sub lords. Use each table's pencil to edit its date, time, location and UTC offset, with optional sidereal longitude overrides. When following the current clock, the table refreshes every minute while Home is open; its refresh button updates to the present time and clears longitude overrides. Reset returns to native birth data or the current clock. Hour and day lords follow local sunrise and sunset; unavailable sunrise is indicated. Retrograde lords appear in red. RP aspect columns use Western major aspects with a 3° orb, with the Ascendant representing cusp aspects in ephemeris tables.
- Enter the birth details, then complete the Raphael houses. In **Planet positions**, choose **Automatic KP ephemeris · 05:30 AM** to fill both dated ephemeris rows and the birth date’s 05:30 sidereal time. This choice stays active as birth details and ayanamsha change, and travels with `.lkp` backups. Dates before 05:30 use the preceding day and birth date; later births use the birth date and following day. The reference time follows the entered standard meridian: 82°30′ means 05:30 IST / 00:00 UTC. Edited row dates are supported within seven days of each other, with one row on the birth date; changing birth details resets the usual adjacent pair.
- In **Birth details → Ayanamsha source**, choose **Uploaded annual KP table** to use the supplied Table IV-A. All 287 rows (1861–2147) are embedded; calculations use the DMS column as requested. The original arc-seconds column and its 44 differences in 2104–2147 remain visible under **Review uploaded annual ayanamsha table**. Annual entries are interpreted as January 1, 00:00 UTC values and interpolated over each actual calendar year, including leap years. For 15 July 1986, the calculation is **23:33:30 + 00:00:27 = 23:33:57**. This source applies to natal automatic ephemeris rows, ruling planets, transit searches/charts, Panchang and daily ephemeris at their own dates.
- The annual table supports January 1, 1861 through January 1, 2147; a later 2147 date needs a 2148 anchor or manual entry. Its source choice is included in `.lkp` files. Editing the annual baseline or daily addition switches to Manual, and old chart files keep Manual mode. Ayanamsha remains angular DMS above 24°, including **24:06:50** on January 1, 2026.
- **India place search** beside location fields works offline with all 557,995 populated-place records in the pinned GeoNames India mirror, covering all 36 current states and union territories. Filter by state/district and type at least three letters; select a result to fill the place, latitude, longitude and India UTC offset without changing the birth/query date or time. It is available in Birth details, Ruling Planets, Transit Chart, Panchang, Nadi and both matchmaking profiles. Manual coordinates remain editable. Abandoned/historical places and unknown administrative codes are labeled. This is the mirror's full available coverage, rather than a guarantee that every Census village appears.
- **Raphael houses → Original Raphael table · PDF reference** opens a PDF from your device beside Bhav Sadhan. Use its latitude/ST entries to fill the existing six-cusp brackets. The viewer is session-only and does not infer values from OCR. An original all-latitude public-domain edition has not been embedded: its source server was inaccessible in this cloud environment.
- The **Sidereal time** worksheet has its own Automatic/Manual source selector. Automatic mode calculates local sidereal time at the standard meridian at 05:30, then retains the worksheet’s traditional LMT and 10/6 correction. For 15 July 1986 at the India standard meridian, the baseline is **01:00:13**. Raphael house-table brackets are still entered separately.
- Editing a generated planet position switches that worksheet to **Manual ephemeris entry**; editing the 05:30 sidereal time switches its source to Manual. Manual mode supports printed KP ephemeris values and the included 9–11 October 1931 sample. Older chart files open in Manual mode to preserve their original entries. Automatic generation covers 1900–2100; both dated endpoints must fall within the supported range. Invalid automatic inputs clear generated values and show the reason.
- **Tab 6 — Planet positions** calculates the hours and minutes automatically from daily angular motion and the birth-time difference from 05:30. The dated rows determine the motion's direction; births before 05:30 receive a signed correction. The correction components are angular degrees/minutes/seconds, not clock durations.
- Enter the seven classical planets and Rahu. Ketu has no independent calculation column: it is derived exactly 180° (six signs) opposite Rahu with identical degrees, minutes and seconds within its sign.
- Use the sidebar to move between Home, the worksheets, Western Aspects, Transit and Report. Dense worksheet tables scroll sideways on small screens.
- **Calculate** refreshes the worksheet results and chart. The overview shows local mean time, ayanamsha, and longitude difference.
- **Tab 7 — MD & AD** calculates Mahadasha and Antardasha together using the Moon's sign and exact degrees, minutes and seconds. Use the MD/AD shortcuts at the top and choose a Mahadasha to view its nine Antardashas in the same planet, years, months, days, start-date and end-date format. The birth Antardasha is marked with its remaining balance; the full birth Mahadasha includes periods before birth. Durations follow the worksheet's 12-month year and 30-day month convention. Exact fractions determine the birth lords; displayed durations and calendar dates are rounded to whole days. For example, a Moon at Libra 6°37′11″ belongs to Chitra/Mars, with 8.8725 worksheet days remaining (displayed as nine days).
- **Tab 8 — Significators** shows four-fold and six-fold planet/house tables and four-step theory cards. Changes to completed worksheets refresh them automatically; incomplete or unordered cusp data clears the results. The column definitions appear beside each display.
- Each South Indian kundali cell places cusp numbers and degrees on the left, and planet names and degrees on the right. A smaller line beneath each entry shows its calculated **(SGL–STL–SBL)**: sign lord, star lord and sub lord. Crowded entries are spaced independently in each column, including on Home and in printed reports.
- Right-click the kundali on Home or its worksheet to select **North Indian** or **South Indian**. A visible layout selector also works on touch screens; keyboard users can press Shift+F10 to open the menu. The chosen layout appears on Home and in the printed kundali, and is preserved in saved charts and `.lkp` backups. South Indian manual notes remain intact when switching layouts.
- Basic planet and house tables appear below the kundali, including nakshatra/pada, occupancy, ownership, sign/star/sub/sub-sub lords, cusp lords, aspects and cusp conjunctions. Aspects use Vedic sign rules; the default 3° cusp-conjunction range is editable in Tab 8. The software displays the nine traditional grahas.
- Planet references in the basic and significator displays carry **[+]** when no graha occupies that planet's stars, **[#]** for its own star, **[*]** for its own sub, **[R]** for retrograde motion, and **[C]** for combustion. An empty house carries **[e]**. Markers and their legend appear on Home and in reports. Astrologer settings → Notations can hide the markers or change combustion to a uniform 8.5° Sun separation. The default limits match the requested values: Moon 4°, Mars 8°, Mercury 5° (3° retrograde), Venus 6° (4° retrograde), Jupiter 5°, and Saturn 8°; Sun, Rahu and Ketu receive no combustion marker. Star occupancy and empty houses count the nine grahas, including the planet itself; Fortuna does not change these markers.
- **Western Aspects** separately calculates planet-to-planet and planet-to-cusp aspects from the natal worksheet longitudes. Its catalog includes 0°, 22.5°, 30°, 36°, 40°, 45°, 60°, 67.5°, 72°, 80°, 90°, 120°, 135°, 144°, 150°, 160° and 180°, with English/Marathi names and short codes. Five major aspects are selected initially; use Select all 17 or select individual angles and orbs. Each angle has an editable colour category using the supplied legend; category labels appear in results as well as colours. These display categories do not change the angular calculation. Each result shows the aspect, code, shortest zodiac separation and actual orb. Planet pairs appear once.
- **Transit** automatically searches the native’s current MD, AD or PD period (PD initially selected), displaying all three lords and exact start/end times. It selects the active periods at the present moment in the native birth time zone; manual From/Through dates are removed. The selected display time zone changes labels without changing the search interval. It searches the full selected period and returns entry/exit date-times in India time or UTC. Event mode selects significators automatically from the relevant houses using four-fold, six-fold or four-step calculations. Event house presets are editable; choose transiting planets and whether their star/sub lords must match together or separately.
- Mutual transit mode automatically uses the MD, AD and PD lords active now in the native birth time zone, or manually selected lords. Choose a direction and Rashi, Nakshatra or Sub level. Sun mode checks both simultaneous combinations: MD Rashi with AD Nakshatra, and MD Nakshatra with AD Rashi. Targets can be sectors ruled by the lord or sectors occupied by the target natal planet; the selected lords stay fixed throughout the search. Results include retrograde reentries and mark intervals clipped by the requested range.
- **Transit Chart**, directly below Transits in the sidebar, calculates the selected date, time and location. It shows planet/cusp longitudes, motion, sign/star/sub/sub-sub lords and Nakshatra/pada, two North Indian Rashi/Bhav charts, and the native’s MD/AD/PD timeline for that date. Switch between natal cusps and calculated transit Placidus cusps. Now, forward/backward stepping and real-time controls update the moment; stepping by months or years clamps the calendar day at month ends. The natal worksheets remain unchanged. Print chart opens the report selector with Transit Chart selected.
- **Save chart** stores the editable worksheet data and manual kundali notes in the current browser. **Load** restores the saved chart and recalculates outputs.
- The toolbar's backup menu exports/imports **`.lkp` chart files**, including worksheets, aspect/transit settings, ruling-planet overrides, manual notes and the cover photo. These files contain the calculator's JSON backup format; earlier `.json` backups can still be imported. Imported charts must be saved separately to persist in the browser.
- **Manual Edit** allows plain-text notes in the South Indian kundali. They stay in place until **Auto Fill Kundali** returns to calculated chart values.
- **Print report** opens the report controls. Select individual pages or use **Select all**, then click **Print selected pages** to print or save a PDF. There are twenty-four selectable sections, including **Single-page report**, **Western Aspects**, **Transit**, **Transit Chart**, **Transit Panchang**, **Ephemeris**, **Prediction**, **Event Promise**, **Nadi Astrology**, **Ruling Planets** and **Matchmaking**, with **Mahadasha (MD)** and **Antardasha (AD)** as separate choices. The single-page option follows the supplied two-column A4 layout: kundali, native details, Panchang, four-fold significators, basic planet/house calculations, all nine MD/AD tables, and astrologer contact information. It uses the current chart and calculated dates. To print it alone, click **Clear selection**, choose **Single-page report**, and click **Print selected pages**. Kundali dotted divider lines are omitted from PDF output. Aspect reports include the chosen angles, orbs and current planet/planet and planet/cusp tables. Transit reports include the chosen search criteria and completed date results; run the transit search before printing it. Long result tables continue onto additional A4 sheets with repeated table headers. Transit Chart prints the selected moment’s tables and both charts. The front page includes Ucchishta Mahaganpati, the native's name, birth details and birthplace, and the astrologer's name, phone and address. The remaining pages include each significator method and the basic calculation tables directly below the kundali. Allow the report window if your browser blocks popups.
- **Prediction** analyses all twelve cusp lord chains against the supplied `Prediction.xlsx` catalogue. Choose CSL → its star lord → its sub lord, or the cusp's own lords; use four-fold or six-fold significators and select which layers contribute. The main house selects the cusp, and a numeric supporting group matches only when every required house occurs in the selected union. An optional checkbox also requires the main house. English and Marathi entries are joined by serial: 1,612 catalogue entries, 1,398 clear numeric groups, and 214 entries with conditions or language differences kept for review. Search, filter, inspect each entry's source and contributing houses, and preview or print the selected cusp's filtered sheet. The sheet reports house-group matches; further KP decision, opposing-house, strength and timing rules can be applied when supplied.
- **Prediction → Reference library** contains all 6,213 ordered records from the seven uploaded text files: Gemstones (18), House Results (2,869), Short Dasha (391), Detailed Dasha (1,017), Mahadasha and Remedies (48), General Predictions (824), and Events Directory (1,046). Search by text or source key and filter by category/subgroup; pages show 30 entries. Repeated keys, multiline text, templates and original source lines are preserved. Printing includes every filtered entry across all pages. The Prediction CSV button is removed, and Gemstone Guidance hides its reference CSV button. These reference texts remain separate from the Excel-based house-group analysis: ambiguous encoded keys and remedies are not treated as automatic KP rules.
- **Birth details → Chart type** offers Natal and KP Horary. The 249 system partitions the 27 nakshatras into Vimshottari subs and splits intervals crossing a sign boundary; the 2,193 system subdivides those intervals into sub-subs. Both use the selected interval's starting longitude as the numbered Ascendant. Horary computes Placidus cusps from that Ascendant and the query latitude; planets use the actual entered query instant, UTC offset and DST minutes. Fractional arcseconds are retained internally for sub-sub boundaries. Toss, Instant Prashna, category, gender, question and notes are available. Natal mode keeps the existing Raphael worksheet and 05:30 ephemeris calculation.
- **Event Promise** selects a cusp and event from the existing house-group catalogue. Inspect CSL, its star and sub lord, and their next lord layers with four-fold or six-fold house significations. Select contributing layers or override their houses manually; favourable, neutral and unfavourable groups are editable. Every numeric alternative is compared explicitly and conditional rules remain visible for review. The result states full, partial or absent house-group coverage; it does not invent additional promise-strength rules.
- **Nadi Astrology** shows nine planet/star/sub chains in a 3×3 worksheet, with event-house highlights. Use the native worksheet or independent query-time planets with natal or selected-moment Placidus cusps. Date/time, location, second/minute/hour/day/month stepping, real-time updates, CSV, notes and a Transit Chart shortcut are included. Query calculations leave the natal worksheets unchanged.
- **Ruling Planets** is a separate query workspace with Ascendant/Moon/Rahu/Ketu SGL/STL/SBL/SSL, sunrise-based day/hour lords, and optional 1–249 numbered Ascendant. Record a question, expected window and astrologer note; save, load or delete up to 30 query memos. Memos preserve their original RP snapshot and calibration, and travel with `.lkp` files. Calculate again to use current ayanamsha settings. Use as horary chart explicitly transfers the selected query into Birth details.
- **Matchmaking** calculates eight Ashtakoota scores out of 36 from two independently entered charts, with exact Moon sign, nakshatra and pada. Its disclosed base lookup convention includes Varna, Vashya, Tara, Yoni, Graha Maitri, Gana, Bhakoot and Nadi; reference variants are explained under method details, and additional dosha-cancellation rules are not inferred. Manglik checks use whole-sign Mars houses from selected Lagna, Moon and/or Venus bases: North 1/4/7/8/12, South 2/4/7/8/12, or Both 1/2/4/7/8/12. Each profile supports UTC offset and DST. Save/load/delete up to 30 pairs, calculate the six-category KP index and shared marriage periods, or preview the result for printing; saved pairs travel with `.lkp` backups.
- **Transit Panchang** calculates tithi, paksha, yoga, karana, nakshatra/pada, Moon sign, civil weekday, sunrise and sunset for the selected local moment and place. It includes nine grahas and the Ascendant with sign/star/sub/sub-sub lords. Use **Now** or copy the selected **Transit Chart** moment. The entered UTC offset determines local dates and times; no separate DST adjustment is assumed.
- **Ephemeris** generates nine sidereal planetary positions per day at a selected local time and UTC offset, for up to 366 days. It shows DMS, nakshatra/pada, SGL/STL/SBL/SSL, retrograde motion and combustion using the saved limits. Print includes every calculated day. Inputs and chart changes invalidate stale results; recalculate after editing or restoring a chart. These tab controls travel with `.lkp` backups.
- In **Report**, use **Choose cover photo** to select the original JPG, PNG or WebP from your device. The full image appears on the front page without cropping. It is saved in this browser and included in `.lkp` chart backups; use **Export chart** to move the chart and photo to another device.
- **Astrologer settings → All Settings** includes Display, Chart Calculation, Notations, Ruling Planets, Significators, Aspects, Language, Software Presets, Themes and Astrologer Info. Choose chart/font sizes (including Home tables), planet symbols, birth information, tooltips, date/time formats and screen layout. Calculation controls set transit cusps, Fortuna's formula, cusp-conjunction range, Ketu's optional Vedic aspects, ruling-planet refresh/orb, and Western aspect presets/orbs. Language changes settings labels and chart names. Presets populate a draft; **Save** applies and stores your choices, while **Cancel** restores them. Preferences travel with `.lkp` backups. The Astrologer Info page keeps the name, contact number and address used in reports.
- **Show Fortuna** adds an optional calculated point to natal and transit diagrams. Its day formula is Ascendant + Moon − Sun; its night formula is Ascendant + Sun − Moon. Automatic selection uses the Sun's position above or below the selected cusp horizon; a fixed day or night formula can also be selected. Fortuna is displayed separately from the nine-graha calculations and significators.

Keyboard shortcuts: **Ctrl/⌘ + S** to save, **Ctrl/⌘ + Enter** to calculate, **?** for help, and **Escape** to close mobile navigation or help.

## Transit and current-position calculations

The HTML embeds [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/tree/v2.1.19), including its MIT license, for offline geocentric planetary positions and sunrise/sunset. The embedded minified source has SHA-256 `f41139a87941ea017ab902b954c9389fa27ea72083d7fab4971756d7769d14e6`.

Sidereal longitudes use the selected ayanamsha source. Manual mode advances the worksheet's birth ayanamsha by 50.29 arcseconds per year; Uploaded annual KP table mode interpolates the supplied DMS values at the requested UTC instant. The upload's SHA-256 is `b53381e8cca25d69e5ec140244b7a0256bc6206bcb96e4969d67027cb3bccb46`. Rahu uses the mean lunar-node polynomial, and Ketu stays 180° opposite. Transit Chart uses numerically solved Placidus cusps with actual semi-arcs; polar-circle locations report unavailable transit cusps and can use natal cusps instead. Searches cover 1900–2100 and support full Mahadashas up to twenty years (engine range limit: twenty-one years). Crossings are numerically refined to one second; that refinement is distinct from the underlying astronomical and ayanamsha model accuracy. Automatic MD/AD/PD boundaries reuse the native Home Vimshottari timeline, retaining the worksheet’s 360-day duration and calendar-offset convention with exact birth-clock times. Automatic transit lords are those active now and stay fixed throughout the selected period. Searches refresh current periods before running and invalidate results when the native or selected period changes. Event results are matching transit intervals for the displayed criteria.

Automatic worksheet ephemeris rows use this same offline engine and selected KP ayanamsha. Tab 6 interpolates their rounded sidereal DMS using daily motion; it does not subtract ayanamsha again. This retains the traditional 05:30 worksheet calculation rather than evaluating the planets directly at the birth instant. It can differ from direct instantaneous values, especially for the Moon, and is not a digitized edition of a printed KP ephemeris.

## Private calculation server

Run the customer interface with `python3 protected/server.py --port 8080` from this checkout. It requires Python Playwright and Chromium (the same installed tools used by the browser regression suite). `CALCULATOR_CHROMIUM` can override the Chromium executable. The server binds to loopback; use an authenticated HTTPS reverse proxy for a private deployment. Do not serve this checkout as a public static directory.

Customers receive a script-free interface snapshot plus a small interface script. The original calculation code remains in a private Chromium worker. Calculation worksheets, formula rows and their report selections are removed from customer responses. Customer actions are restricted to controls present in their own session; hidden calculation inputs and source-file requests are rejected. Formula edits require developer access to the private source and a server restart. This does not make source already distributed in an HTML file or public repository secret. Keep deployment source private; this ZIP is a developer package, not a buyer installer.

New server charts use automatic 05:30 planet positions, the uploaded annual KP ayanamsha and computed Placidus natal cusps; numbered horary retains its existing calculation method. The standalone developer HTML retains manual Raphael worksheets. Importing a worksheet file into the customer server restores its user data and recomputes the chart automatically, rather than accepting hidden worksheet overrides.

Coordinates in the customer forms and location summaries use DMS with N/S and E/W. Numeric coordinates remain exact internally and in `.lkp` files; display rounding does not change saved coordinates. Themes in Astrologer settings now cover reference window backgrounds and table headers. Reports have double-line frames, including a repeated frame on printed sheets. The desktop Transit Chart is compact without altering its calculation data or report diagrams.

The local server supports up to four isolated sessions, expiring after 30 minutes without requests. Save chart downloads a `.lkp` file; Load imports it. Session data is not a database and should be downloaded before closing the browser. This local worker is not yet a hosted commercial service; customer accounts, HTTPS and capacity must be supplied by the deployment.

Additional checks: `python3 -m unittest discover -s tests -p test_protected_server.py -v` verifies source isolation, protected controls, native recalculation, DMS persistence, selected printing and session separation.

Release verification: all 80 existing calculator cases were exercised. A Transit SVG edge alignment failure was corrected; its affected tests and the enlarged Home font/geometry checks passed on rerun. Seven additional server tests passed. A two-page A4 PDF was rendered and both physical sheets contained repeated double-line frames. Hosting and customer authentication have not been deployed.

Nadi Astrology now follows the supplied reference window: planetary and cuspal position tables on the left, the selected Rashi chart in the middle, native five-level Vimshottari and selected-chart ruling planets on the right, and the nine Nadi coordinate panels below. Existing time-slice controls, event selection, CSV and print actions remain connected. Changing the Nadi moment updates its diagram, tables and ruling chain without editing the native chart. Native dasha is labelled explicitly; extra event criteria, notes and gazetteer filters can be expanded when needed. The layout and selected-model synchronization were checked at 1920, 1280 and 390 pixels, together with selected printing and the protected customer interface (three tests passed).

The uploaded KP handbook is preserved in `data/kp-handbook.pdf`. Its 453 extracted event entries and original table rows are in `data/kp-handbook-rules.json` and embedded for offline use.
