# Remedy CRM — current release 1.6.0

- [Windows setup](Remedy-CRM-Setup-1.6.0.exe)
- [Android APK](Remedy-CRM-Android-1.6.0.apk)
- [Standalone HTML ZIP](Remedy-CRM-HTML.zip)
- [Installation, backup transfer and printing guide](REMEDY-CRM-START-HERE.md)

Includes the simpler CRM, customer/accounts reports with bar diagrams, A5/A4 report previews, and tighter A5 remedy/Matrugaya letterhead spacing with an adjustable top margin.

Remedy CRM has its own Windows/Android identities and storage. Install it separately and restore your exported section backups to transfer records. Use the new Remedy CRM shortcut/icon. Native Windows installation and Android/physical printing still need checks on the target devices; the Windows installer is unsigned. SHA-256 files are next to each download.
