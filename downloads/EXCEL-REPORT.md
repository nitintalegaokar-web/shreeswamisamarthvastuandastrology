# Print saved bookings from Excel

Use KP Master **1.2.0 or newer**.

1. Open **Matrugaya Bookings**.
2. Select **Saved bookings / नोंदी**.
3. Click **Export Excel / एक्सेल** and save the `.xlsx` file.
4. Open it in Microsoft Excel.
5. Choose **File → Print**, select a printer, and print.

The report includes all saved bookings: booking ID, customer, mobile, departure date, persons, total, advance and remaining balance, followed by totals. It is set to A5 landscape, one page wide and as many pages tall as needed. Column headings repeat on later pages. You can change the paper size in Excel if your printer needs another format.

Settings print selections determine which consultancy/astrologer details appear in the heading. Numeric payment cells, balance formulas and totals are included; phone numbers and IDs remain text. Export works offline. The button is enabled after at least one booking has been saved.

Native Excel printing requires Excel on your computer; workbook data, formulas, cached totals and print settings were validated with an independent reader.
