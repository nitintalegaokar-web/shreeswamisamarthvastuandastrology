# KP MASTER 1.2.10

Release date: 20 October 2026. Event significators mode now follows the Transit Reader rule only: the moving planet, nakshatra lord and sub lord must all be event significators. No Rashi/transit-house position, ruling-planet or extra Sun/Moon/Jupiter/Saturn filter is used in this mode. Historical DBA searches, CSV and print carry this rule. Rule-matching windows do not guarantee a real event date.

Windows: Windows 10/11 x64. Owner calculator, activated Customer calculator and the separate Owner Activation tool retain their existing identities. Installers are unsigned; native Windows installation has not been run here.

Android: Android 9+. Version 1.2.10, versionCode 10214. Uses the same certificate as the prior fresh-install 1.2.8 APKs, so those installations can update. For an app with the older original certificate, export your backup before uninstalling/reinstalling. Physical-phone installation has not been tested here.

iPhone: no native IPA is included. Native packaging requires macOS/Xcode and Apple signing/provisioning. APK files are Android-only. The web editions require HTTPS hosting for iPhone use and have not been tested on a physical iPhone. Keep the unlocked Owner edition private.

HTML backup: extract completely and open KP-MASTER/index.html. The ZIP includes all available reference/data sources and a per-file checksum manifest. The workspace Kundali Backup and Report Photos folders contain instructions only; browser/device-local files and private keys are unavailable and are not included.

Checks: 40 desktop unit-test files; Android licence/demo tests; APK signatures/alignment and byte-parity; mobile browser exports/backups/A4 PDF; all three Windows installer payloads and packaged source verified.
